Why This Fix Works on GitHub Pages

Problem: GitHub Pages sometimes serves PDFs with Content-Disposition: attachment or wrong MIME when files contain large images, causing iframe and even new-tab open to fail or download instead of render.

Solution: This page uses fetch(pdfUrl).then(r=>r.blob()) → URL.createObjectURL(new Blob([blob], {type:'application/pdf'})). The browser then renders the blob URL (blob:https://...), not the GitHub URL. GitHub's headers are bypassed entirely.

Fallbacks: 1) Direct download (always works), 2) Open Raw (tries GitHub direct), 3) PDF.js viewer which also fetches as ArrayBuffer and renders via Canvas, completely independent of browser PDF plugin.
